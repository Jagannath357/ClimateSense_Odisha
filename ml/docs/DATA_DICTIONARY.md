# Data dictionary

`T2M`, `T2M_MAX`, `T2M_MIN`, and `T2MDEW` are degrees Celsius; `RH2M` is percent; `PRECTOTCORR` is mm/day; `WS2M` is m/s; `ALLSKY_SFC_SW_DWN` is MJ/m²/day; `PS` is kPa. `YEAR` and `DOY` come from the NASA export. `district` and `source_file` are provenance fields. Units are taken from each file's NASA metadata block.
